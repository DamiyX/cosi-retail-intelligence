# Prepared chart capture tail

Source implementation only. Examples are disabled/unbound. No phone access at
import, no installation/pairing/launch/export/model operation, and no capture
authority from editing a JSON file. Use only the later reviewed device packet.

After source/build audit, freeze a packet with the actual APK/source and known
phone/sandbox/display. Its hash and the current finite Track B lease must match
the execution charter. The charter records fresh human READY with host monotonic
time. Keep one existing output directory per case under the phone experiment run.

`session.py packet.json charter.json` captures one pre image, then prints its
path/hash. The executor must actually inspect that image for the complete chart,
eight readable markers and guide extent. Within30 seconds write an exclusive
`pre-qualified.json` with `sceneQualified:true`, `preSha256` and `packetSha256`.
This is agent visual review, not another user confirmation or screenshot. If
unqualified/stale, stop; no screenshot/capture retry or automatic new READY.

The same live process then performs one ACK/shutter, reads the fixed compact
native-bound status, fsyncs one post PNG before other diagnostics and closes a
settled preview. No model/chat round trip intervenes between shutter and post.
The120-second human READY window is rechecked immediately before dispatch. A
20-second terminal-observation timeout retains an explicitly unconfirmed post
if available; it never proves settlement or permits another shutter.

Every effect writes an exclusive intent before dispatch. Any intent without done
is consumed/uncertain. There is no effect-resume API. Process/foreground/view/
source/APK/lifecycle changes refuse. Standard-library PNG chunk/CRC bounds do not
replace actual visual/registration review. Two images per assigned case; all
saved/attempted screenshots remain counted, including unqualified evidence.

`PinnedAdb.memory_sample()` is a bounded read-only utility outside the critical
tail. Collect only the planned own-package/aggregate samples. Missing fields are
unavailable, not zero; no memory/leak/GPU-fix guarantee follows from them.

Tests should inject a fake adapter/clock and must not construct a live transport
or execute the disabled examples. Production source stays unbound until source
freeze; physical testing needs its own reviewed/amended photo budget.
