# Empty future capture template

`benchmark.json` contains no captured observation, candidate, device, export or
runtime. Null bindings intentionally fail validation until exact independently
reviewed declarations and dataset identities are supplied. Never substitute toy
identities for real prerequisites. No runner is included.

Copy into ignored `runs/` or approved private storage when real work is authorized.
Keep unmeasured observations null and record every failure and intentional warmup.
Each observation uses `{value, methodId, evidenceId}`; identifiers reference a
separate human review packet. Trials use unique IDs, an explicit stage/phase,
method/evidence IDs and an outcome. Failed elapsed time may be null; successful
elapsed time must be a finite nonnegative number. Inference/result trials bind an
exact `{entryId, assetSha256}` in the supplied inventory. See DEVICE_BENCHMARK.md.

Use pseudonyms and public-safe identifiers, never serials, accounts, paths,
photos or raw notes. No physical evidence is captured by filling this template.
