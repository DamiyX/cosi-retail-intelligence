# Backend foundation

M0 contains CLI configuration only. There are no business tables, policies,
functions, seed data, or linked hosted project.

Use the root-pinned CLI: `npm exec -- supabase --help`.
The configuration was generated by `supabase init`; migration, function, and
test directories are reserved for the milestones that need them.

## Normal development

The mobile shell runs without a backend or Docker. The approved product backend
is a hosted **development** Supabase project, selected separately from production.
Do not create or link a guessed project.

Before linking, verify the intended development project reference, then discover
the exact command with `npm exec -- supabase link --help`. Each laptop authenticates
separately; tokens and database passwords never enter Git or the mobile app.

## Future schema work

Use ordered SQL migrations in `migrations/`; preserve domain meanings and add
store-membership-aware RLS/grant tests alongside exposed tables. Discover migration
commands with the pinned CLI's help. No dashboard-only schema changes.

`functions/` is reserved for trusted server operations. `tests/` will contain
database/RLS tests. M0 does not claim that these later boundaries are implemented.

A local Docker backend is optional for future integration tests. Starting/resetting
it is not required to preview M0. Local config does not configure a hosted project.
